# 55: Define Business-Relevant Units

**Specification Version:** 1.9.0

**Status:** Accepted

**Slug:** 55-define-units

**Implementation Types:**

* None

## Descriptive Statement

Define business-relevant unit(s) (e.g., cost per order/user/GB-item).

## Supplemental Guidance

These are scored as a bucket because you can do them in any order. Targets usually arrive last,
because setting one means agreeing what good looks like and that conversation needs the metric to
exist first.

Item 1 covers two different kinds of unit. A resource efficiency metric such as cost per GB stored
is engineering facing and moves when the architecture changes. A business unit metric such as cost
per tenant is finance facing and moves when the business does. A practice that picks only one has
half the picture, and the Framework expects fully loaded costs to reach the second by the Walk tier.

A unit metric with no forecast and no anomaly detection is a number on a dashboard, and nobody finds
out it moved until somebody opens the dashboard. Item 4 puts the unit on the same footing as absolute
spend, which already has both.

Action 56 documents the inputs and formulas behind each unit and action 60 communicates the wins.
This action covers choosing the units and setting targets for them.

## Scoring Guide

**Weight:** 1.0

### Formula

Measured over: the unit metrics the practice has defined. A practice holds few enough units to
enumerate, so items are assessed against each unit metric rather than as a coverage rate.

* Define cost drivers from finance/business (the business volume that drives cost is named with Finance,
  such as orders, users or transactions)
* Gather metrics on a cadence (the volume is collected on a stated schedule with a named owner rather
  than pulled on request)
* Set goals/targets (each unit metric carries a target value and the period that target applies to)
* Set up forecasting and anomaly detection on units (the unit metric itself is forecast and alerted on,
  not only the absolute spend behind it)

10*Ceil(x/4)
