# 74: Document Licensing Models

**Specification Version:** 2.0.0

**Status:** Accepted

**Slug:** 74-document-license

**Implementation Types:**

* None

## Descriptive Statement

Document licensing models and constraints; tag for allocation/Chargeback.

## Supplemental Guidance

These are scored as a bucket because you can do them in any order. Most practices record the model
first because it comes off the contract, and discover the metered charges when an invoice jumps.

Item 2 matters because the two directions are not symmetric. An organization can usually add licenses
part way through a contract but cannot reduce them until renewal, so a team that over-commits carries
the cost to the end of the term. Recording which way a given agreement moves is what makes a renewal
date worth watching.

For item 3, a license priced per seat can carry charges for access
counts, API usage, or stored data, and a practice tracking only the seat count will forecast the
wrong number.

No coverage rate applies. An agreement list is short enough to read, so an assessor checks each one
rather than sampling.

Action 73 inventories the licenses and maps them to resources. This action records what the terms of
each one are. Action 12 in the Cost Allocation capability scores tagging standards generally; item 4
here is narrower, covering only the tag that marks a resource as running under an existing license.

## Scoring Guide

**Weight:** 1.0

### Formula

Measured over: every license and SaaS agreement held during the review period.

* Model recorded (each agreement records whether it is an organizational agreement, perpetual,
  as-a-service, or a marketplace purchase)
* Change terms recorded (whether licenses can be added mid-contract, and when they can be reduced)
* Metered charges recorded (charges beyond the license itself, such as access counts, API calls, or
  stored data)
* Bring your own license eligibility tagged (resources running software under an existing license
  carry a tag identifying them)
* Allocation target named (each agreement records the cost center its cost reaches)

10*Ceil(x/5)
