# 93: Integrate Cost Data In Workflows

**Specification Version:** 2.0.0

**Status:** Accepted

**Slug:** 93-integrate-cost

**Implementation Types:**

* None

## Descriptive Statement

Integrate cost data into forecasting, budgeting, procurement workflows.

## Supplemental Guidance

These are scored as a bucket because the three workflows are independent. Procurement often
integrates last, because it sits furthest from the engineering tooling most practices start with.

Item 4 separates integration from reporting. A monthly deck emailed to budget owners is not
integration, because the decision happens in the budgeting tool and the deck is somewhere else.

With item 5, the procurement team deciding a renewal against data three months
old will make a worse call than one that is aware the data is three months old and waits.

The Forecasting, Budgeting, and Invoicing capabilities score what those workflows do with the data.
This action scores only whether the data reaches them.

## Scoring Guide

**Weight:** 1.0

### Formula

Measured over: the forecasting, budgeting, and procurement workflows the organization runs.

* Forecasting consumes cost data (the forecast is built from the same cost data the practice
  publishes, not a separate extract)
* Budgeting consumes cost data (budget setting and tracking draw on it)
* Procurement consumes cost data (renewal and purchase decisions see current and committed spend)
* Delivered where the work happens (the data reaches each workflow in the tool its owners already
  use rather than a FinOps report they must seek out)
* Freshness stated (each workflow records how current the data it receives is)

10*Ceil(x/5)
