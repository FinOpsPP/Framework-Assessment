# 24: Define Severity & Response Slas

**Specification Version:** 1.9.0

**Status:** Accepted

**Slug:** 24-define-severity

**Implementation Types:**

* None

## Descriptive Statement

Define severity tiers, thresholds, and response SLAs; publish runbooks.

## Supplemental Guidance

Severity tiers without thresholds are opinions, which is why items 1 and 2 are separate. A tier
called high that nobody can test against a number will be argued about every time an alert fires.

Item 5 measures the runbooks. A runbook that does not resolve the case
it was written for sends the responder back to improvising, and the published document hides that
until somebody counts.

The Framework does not define severity levels or a response time target, so both are yours to set.
What it does expect is that alerts of appropriate urgency reach an event management or ticketing
process rather than an inbox.

Item 6 asks whether a root cause analysis happened. Action 27 scores how good it was, stepping
through ownership, cause, classification, remediation and preventive control. A practice can tick
item 6 here by writing something in a field and still score poorly on action 27.

## Scoring Guide

**Weight:** 1.0

### Formula

Measured over: the severity tiers the practice defines, and every runbook execution during the review
period for item 5. A tier set is small enough to enumerate, so items 1 to 4 are assessed against each
tier rather than as a coverage rate.

* Defined severity tiers (a fixed set of named severity levels exists)
* Thresholds associated with severity tiers are defined (each tier carries a number that places an
  anomaly in it, such as a variance amount or a percentage)
* Defined and adhered to response SLAs (each tier carries a response time target, and adherence against
  it is reported for the period)
* Published response runbooks (a runbook exists per tier or anomaly type and is reachable by whoever
  responds)
* Runbook percent successful or completed (the share of runbook executions that resolved the case
  without improvisation is measured)
* RCA completed after alerts (a root cause analysis is recorded for the severity tiers that call for one)

10*Ceil(x/6)
