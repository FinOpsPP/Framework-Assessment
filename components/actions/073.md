# 73: Inventory Licenses & Map Resources

**Specification Version:** 2.0.0

**Status:** Accepted

**Slug:** 73-inventory-license

**Implementation Types:**

* None

## Descriptive Statement

Inventory licenses/SaaS (marketplace, BYOL); map to cloud resources.

## Supplemental Guidance

The denominator is what a practice knows it needs licenses for, not what it owns licenses for. Those
differ, and the gap is the point. A practice that has mapped every license it bought but has no idea
how many unlicensed resources are running is not at 100%, it has not measured the denominator yet.

Mapping means a named link between the resource and the entitlement covering it. Knowing that a
database server needs a license is not a mapping. Knowing which of the forty purchased licenses
covers it is.

A low score here caps most of this capability. Utilization cannot be computed without knowing which
licenses are assigned to what, and compliance cannot be checked against a position nobody has.

Action 74 tags a resource as eligible to run under an existing license, which is a property of the
resource. This action records which specific entitlement is covering it, which is an assignment.
Action 75 brings the entitlement data in; this action is what gets done with it.

## Scoring Guide

**Weight:** 1.0

### Formula

x = Resources and SaaS products requiring a license that are mapped to the specific entitlement
covering them
y = All resources and SaaS products identified as requiring a license
