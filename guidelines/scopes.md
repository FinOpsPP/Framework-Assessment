# How to use Assessment Scopes

Scopes are an important topic in the FinOps community, and they are also a way to narrow down an assessment to a specific area of interest.
Just how doing FinOps for SaaS is a different Scope of using the FinOps Framework, you can run a FinOps Assessment for a SaaS specific scope per team, and so on. 

However,that one assessment doesn't include all of the other cloud based finops tasks.
Thus, we will be documenting a process for using the assessment for various scopes within an organization, 
and how this ultimately turns into an overall score for the org despite having multiple separate scoped assessments.
